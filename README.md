# Hermes Claw

Agence hybride combinant l'intelligence de Hermes avec les outils d'OpenClaw. Permet d'automatiser des tâches complexes, d'obtenir des informations en temps réel et de créer des habilidades personnalisées.

## Prérequis
- OpenClaw installé
- Python 3.10+
- Accêt d'une instance OpenClaw

## Installation
1. Cloner le répo
   `git clone https://github.com/VotreNom/hermes-claw.git`
2. Instaler les dépendances
   `pip install -r requirements.txt`
3. Copier les fichiers de configuration dans ~/.openclaw/workspace/

## Exemples d'utilisation
```bash
openclaw agent run hermes-claw "Quelle météo demain a Paris?"
```
